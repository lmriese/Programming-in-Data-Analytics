# Programming in Data Analytics

A collection of Python-based data analytics notebooks covering data preprocessing, exploratory data analysis (EDA), visualization, and academic data analytics using Python.

## Projects

### Books Data Analysis
Analysis and visualization of book-related datasets using Pandas, Matplotlib, and Seaborn.

### Pandas Data Science Basics
Introduction to data analytics concepts using Python and Pandas for data manipulation and exploration.

### Student Attrition Analysis
A student analytics project focused on preprocessing, cleaning, and analyzing academic and profile datasets to explore student attrition and performance trends.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

- `Books-Data-Analysis.ipynb`
- `Pandas-Data-Science-Basics.ipynb`
